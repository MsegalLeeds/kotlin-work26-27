# Ktor Web Development Work

Your fork of this repository holds the tasks for lab sessions in Weeks 6-11
of COMP2850.

Each task occupies its own subdirectory of `tasks`. Each task has a README,
but you should also consult the [Ktor Web Development Guide][guide] for full
details of what is required. Remember that you should be using private study
time to complete the tasks; you shouldn't be working on them only during
your timetabled lab session.

The `examples` directory holds examples of Ktor web applications. You won't
need to add or change anything in this directory, but you may find studying the
examples to be useful (and some tasks may reference the example applications
and ask you to experiment with them).


[guide]: https://comp2850.github.io/ktor-guide/
